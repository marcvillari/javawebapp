# Nutrition Tracker

A simple, single-page nutrition tracker. No build step, no server, no dependencies.

## Features

- Log foods per meal: **Breakfast, Lunch, Dinner, Snack**
- Track **calories, protein, carbs and fat** against your daily goals
- Leave kcal blank and it's estimated from macros (4 / 4 / 9 kcal per gram)
- Log **body weight** per day, with a 30-day trend chart
- Move between days with the date picker
- Light and dark mode (follows your system)

## Run

Open `index.html` in any browser. Data is saved in your browser's local storage,
so it stays on that device and browser.
